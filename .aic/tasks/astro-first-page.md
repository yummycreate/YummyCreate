# Task: Astro移行と最初のページ(日本語/英語)

## やること

- 静的サイトジェネレーター Astro を導入し、`dist/` をデプロイ対象にする
- 多言語(日本語はルート、英語は `/en/`)。hreflang・canonical・sitemap をビルドで生成する
- ページごと・言語ごとの `status`(draft / reviewed / published)で公開ゲートを作る(published 以外は出力しない)
- トップページを日本語/英語で作る(文面は監修前の下書き)
- Deploy ワークフローにビルド工程を足す(予約名・危険パスのガードは維持)

## 完了条件

- ローカルで日本語/英語のページが表示でき、hreflang・sitemap が期待どおり
- draft の言語版は出力されず、hreflang にも出ない
- `dist/` の全ファイルパスがワークフローのパス検証を通る
- main へのマージ(= 公開)はユーザーの承認後に行う
