# Task: リーダーをスワイプ1回で1ページめくれるようにする

## やること

- ページの境目にスナップ位置を置き、`scroll-snap-type: x mandatory` と `scroll-snap-stop: always` で1スワイプ=1ページにする
- 端のスワイプでブラウザの戻る/進むが誤動作しないよう `overscroll-behavior-x: contain` を付ける
- 止まった後にJSで位置を補正していた処理をやめ、スナップに任せる

## 完了条件

- 公開ページで、スナップ位置がページ数ぶん存在し、途中位置で止めても境目に揃う
- ボタン・矢印キーでの移動、章をまたぐ移動が従来どおり動く
